# Domain 3 — Claude Code Configuration & Workflows

### CCAR-F Domain 3 · 20% of the exam

The main study experience for this domain — concept, quiz questions, and CLI
snippets — lives in [`../app.html`](../app.html) alongside every other domain.
This folder holds one thing app.html can't: a **proper, fully hands-on lab**
you actually build and run with the real Claude Code CLI.

## [`labs/lab_claude_md_hierarchy.md`](labs/lab_claude_md_hierarchy.md)

Covers Task Statements 3.1–3.3 (CLAUDE.md hierarchy, `@import`, path-scoped
rules, commands, and skills with `context: fork`) using a small fictional
project you build step by step: three CLAUDE.md scopes, an `@import`, a
path-scoped testing rule, a shared command, a personal command, and a skill
with full frontmatter. No API key needed — this is Claude Code configuration,
not API calls, so every step is something you can actually run and observe
for yourself.
