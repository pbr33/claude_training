Watch stop_reason. tool_use means execute the requested tool(s) and append a tool_result block matched by the exact tool_use_id, then call again. end_turn means stop — not a hardcoded turn cap, not text-parsing.
Hub-and-spoke: the coordinator, not the subagents, owns all routing. Each subagent gets only what's in its prompt — no automatic inheritance of the coordinator's history. Multiple Agent/Task tool calls emitted in one coordinator turn run in parallel; across separate turns, they'd run sequentially.
A PreToolUse hook runs before the tool executes and can return permissionDecision: "deny" — deterministic, code-level enforcement. A prompt instruction like "always verify the customer first" is guidance the model can still get wrong; the hook physically blocks the call regardless of what the model decided.
